# MauLeaf 叶子图标说明

采用已确认的单片绿色叶子：完整应用图标保留深色圆角背景，菜单栏使用同一设计的白色单叶子剪影（模板图片由系统自动着色）。

不在菜单栏显示数字、电量轮廓、充电状态等。菜单栏图标尺寸 17×17 pt；Tooltip 仍可通过辅助功能读取电池状态。

素材出处：本项目对话生成并确认的叶子视觉方案，主图在 `leaf-icon-source.png`。

## 启动台与 Finder 的图标尺寸

应用的 `.icns` 由 `Scripts/GenerateAppIcon.swift` 从原始 `Assets/MauLeafIcon-1024.png` 生成。原图保留，构建时将完整图案居中绘制在透明画布内：1024 像素画布使用 824 像素主体、四边各 100 像素留白，其他尺寸按相同比例绘制，再由 `iconutil` 打包。

此前直接缩放源图，1024 像素资源的主体宽度约 1020 像素。本机对照中，微信主体约为画布的 80%，Chrome 的 256 像素资源主体约 206 像素；原来的 MauLeaf 因而显得大约 24%。修复针对图标在画布中的占比，未改变叶子设计或菜单栏的 17×17 pt 尺寸。

`./tests/run.sh` 会验证全部十个 iconset 文件的透明外边距、主体比例和居中，避免后续构建重新铺满画布。源 PNG 继续用于应用内图像；Finder、Dock 与启动台使用带留白的 `.icns`。

安装新版前正常退出旧版，再替换 Applications 中的应用。若系统仍显示旧图标，先重新打开启动台或重新登录以更新缓存；不需要删除应用设置或重置启动台布局。
