## 简体中文

ChargeCap 正式更名为 **MauLeaf**。本次统一应用与安装包名称，并重新组织项目首页，让新用户能直接了解用途、功能和使用方式。

### 更新内容

- 主应用更名为 `MauLeaf.app`，独立卸载器更名为 `Uninstall MauLeaf.app`；菜单栏提示、授权文案、可执行文件、源文件和图标资源同步使用新名称。
- 安装包更名为 `MauLeaf-0.7.0.dmg`，两个应用继续内嵌叶子图标。版本为 `0.7.0`，构建号 `20`。
- 保留旧版 Bundle ID、偏好设置键、任务标识和数据目录，继续使用 ChargeCap 已保存的设置及已有 batt 服务。卸载器同时识别新旧主应用并清理对应安装路径。
- 重写 README，介绍整个项目的定位、功能、安装、日常使用、升级、卸载与开发；充电实现和兼容说明整理为独立文档。
- 保留限充、单次/持续充满、高电量处理、自适应功率刷新、窗口外点击收起、底部悬浮提示及正常退出解除控制等现有行为。

### 安装与升级

- 支持 Apple Silicon（arm64），macOS 13 或更高版本。
- 下载本页 `MauLeaf-0.7.0.dmg`，将 `MauLeaf.app` 拖入 Applications。首次安装系统控制组件需要管理员授权。
- 从 ChargeCap 升级时，请先**正常退出旧版**，再打开 MauLeaf；已有正常工作的 batt 服务无需重装。确认升级后可删除旧 `ChargeCap.app`，不要同时运行新旧版本。
- 内部仍可能出现 `ChargeCap` 目录或标识，这是为保留设置与清理旧任务而采用的兼容约定。
- 可使用 `SHA256SUMS.txt` 校验下载文件。

### 构建与验证

- DMG 在本地 Apple Silicon Mac 编译生成后上传。
- 173 项逻辑检查通过，另有离屏 SwiftUI/AppKit 布局回归；普通、处理中和长错误状态的内容高度一致。
- 应用名称、可执行文件、版本、图标、许可证、ad-hoc 签名及 DMG 完整性已校验；保留旧版持久标识。
- 实际 Finder 图标显示、窗口点击、真机充放电及退出流程、物理插拔电源、睡眠和长期能耗未在本次完成验收。

### 已知边界

- 当前使用本地 ad-hoc 签名，尚未进行 Apple notarization；首次打开可能需要在系统设置中按提示允许。
- 强制结束、崩溃或断电可能绕过退出清理，限充设置可能保留；可重新启动后正常退出。
- 单次充满由固定版 batt 的限时解除与后台检查配合实现；睡眠或控制服务停止期间不能保证即时恢复。主动降电量能力以设备实际报告为准。

### 许可证与源码

项目采用 Apache-2.0，保留原始 ChargeCap MIT 声明；内置独立组件 batt 固定为 `v0.8.0`，其 GPL-2.0 许可证保持不变。两个应用均内嵌许可证文本。

本页附带对应版本的 `batt-v0.8.0-source.tar.gz`。MauLeaf 源码可从仓库标签 `v0.7.0` 或本页自动生成的源码归档获取。

## English

ChargeCap is now **MauLeaf**. This release unifies the application and package names and rewrites the project homepage so new users can understand what the app does and how to use it.

### What's new

- Renamed the main app to `MauLeaf.app` and the standalone uninstaller to `Uninstall MauLeaf.app`. Menu bar tooltips, authorization text, executables, source files, and icon assets now use the new name.
- Renamed the installation image to `MauLeaf-0.7.0.dmg`. Both apps continue to embed the leaf icon. App version: `0.7.0`; build number: `20`.
- Preserved the existing Bundle IDs, preference keys, task identifiers, and data directories to reuse ChargeCap settings and the existing batt service. The uninstaller recognizes both main app names and cleans up their installation paths.
- Rewrote the README to introduce the whole project: purpose, features, installation, everyday use, upgrades, uninstallation, and development. Charging implementation and compatibility details are now in a separate reference document.
- Retained charging limits, one-time and continuous full charging, above-limit handling, adaptive power refresh, click-outside dismissal, bottom overlay feedback, and release of charging control on normal quit.

### Installation and upgrade

- Requires Apple Silicon (arm64), macOS 13 or later.
- Download `MauLeaf-0.7.0.dmg` from this page and drag `MauLeaf.app` into Applications. Initial installation of the system control component requires administrator authorization.
- When upgrading from ChargeCap, **quit the old app normally first**, then open MauLeaf. A working batt service does not need to be reinstalled. After confirming the upgrade, you can delete the old `ChargeCap.app`. Do not run both versions simultaneously.
- Internal directories or identifiers may still contain `ChargeCap`. These are retained for settings compatibility and cleanup of existing tasks.
- Use `SHA256SUMS.txt` to verify downloaded files.

### Build and validation

- The DMG was compiled locally on an Apple Silicon Mac before upload.
- All 173 logic checks passed, along with an offscreen SwiftUI/AppKit layout regression check. Content height remained identical in normal, busy, and long-error states.
- Verified app names, executables, versions, icons, licenses, ad-hoc signatures, and DMG integrity. Legacy persistent identifiers are preserved.
- Actual Finder icon rendering, window clicks, hardware charging/discharging and quit behavior, physical power connection changes, sleep, and long-term energy use were not validated in this release's checks.

### Known limitations

- The package is locally ad-hoc signed and has not been notarized by Apple. First launch may require approval through the prompts in System Settings.
- Force quitting, crashes, or power loss may bypass quit cleanup and leave charging limits in place. Relaunch the app and quit normally to release control.
- One-time full charging combines a temporary override in the pinned batt version with background checks. Immediate restoration is not guaranteed during sleep or while the control service is stopped. Active discharge availability depends on the capabilities actually reported by the device.

### License and source

The project uses Apache-2.0 and retains the original ChargeCap MIT notice. The bundled standalone batt component is pinned to `v0.8.0` and remains under GPL-2.0. Both apps embed the applicable license texts.

The corresponding `batt-v0.8.0-source.tar.gz` is attached to this release. MauLeaf source is available from the `v0.7.0` repository tag or the automatically generated source archives on this page.
