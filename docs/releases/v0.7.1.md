## 简体中文

### 更新内容

- 面板底部新增语言切换按钮：点击「English」切换英文，点击「中文」切回中文，即时生效并记住选择。
- 主面板、充电模式、电池与功率状态、安装确认、菜单栏提示及操作反馈提供中英文文案；已有动态提示也可即时切换。
- 语言切换仅改变显示，不重新执行充电指令，不改变模式或上限。
- 版本 `0.7.1`，构建号 `21`，保留叶子图标及原有配置兼容。

### 构建与验证

- 回归检查覆盖语言保存与恢复、动态数值和嵌套错误、切换时无额外充电命令，以及中英文离屏布局。
- DMG 在本地 Apple Silicon Mac 编译生成；中英文资源、图标、许可证、签名及 DMG 完整性已校验。
- 真实窗口点击、系统授权和硬件充放电尚未完成验收。

### 安装与升级

- 支持 Apple Silicon（arm64），macOS 13 或更高版本。
- 下载 `MauLeaf-0.7.1.dmg`，先正常退出旧版，再将 `MauLeaf.app` 拖入 Applications 替换；已有设置和正常工作的 batt 服务继续保留。
- 默认中文，可在面板底部一键切换英文；再次点击「中文」即可切回。
- 可使用 `SHA256SUMS.txt` 校验下载文件。安装包使用本地 ad-hoc 签名，尚未进行 Apple notarization；首次打开可能需要在系统设置中按提示允许。

### 许可证与源码

项目采用 Apache-2.0，保留原始 ChargeCap MIT 声明。内置独立组件 batt 固定为 `v0.8.0`，遵循 GPL-2.0；本页附带对应版本源码 `batt-v0.8.0-source.tar.gz`。MauLeaf 源码可通过 `v0.7.1` 标签或本页源码归档获取。

## English

### What's new

- Added a language button at the bottom of the panel. Click “English” for English or “中文” for Chinese. Changes apply immediately and your choice is saved.
- Localized the main panel, charging modes, battery and power status, installation confirmations, menu bar tooltips, and operation feedback. Existing dynamic messages can also switch immediately.
- Language selection only changes presentation. It does not execute charging commands or change the mode or limit.
- Version `0.7.1`, build `21`. The leaf icon and existing settings compatibility are preserved.

### Build and validation

- Regression checks cover language persistence and restoration, dynamic values and nested errors, no extra charging commands on language changes, and offscreen layout in both languages.
- The DMG was compiled locally on an Apple Silicon Mac. Localization resources, icons, licenses, signatures, and DMG integrity have been verified.
- Actual window clicks, system authorization, and hardware charging/discharging have not been validated.

### Installation and upgrade

- Requires Apple Silicon (arm64), macOS 13 or later.
- Download `MauLeaf-0.7.1.dmg`, quit the old app normally, then drag `MauLeaf.app` into Applications to replace it. Existing settings and a working batt service are preserved.
- The interface defaults to Chinese. Click “English” at the bottom of the panel to switch, or “中文” to switch back.
- Use `SHA256SUMS.txt` to verify downloads. The package is locally ad-hoc signed and has not been notarized by Apple; first launch may require approval through the prompts in System Settings.

### License and source

The project uses Apache-2.0 and retains the original ChargeCap MIT notice. The bundled standalone batt component is pinned to `v0.8.0` and remains under GPL-2.0. Its corresponding source, `batt-v0.8.0-source.tar.gz`, is attached to this release. MauLeaf source is available from the `v0.7.1` tag or the source archives on this page.
