## 简体中文

### 更新内容

- 修复应用图标在启动台中相对其他应用偏大的问题。原 ICNS 直接将图案缩放至画布边缘；新流程在各尺寸统一加入透明外边距，主体占比约为 80%。
- 保留原始叶子设计、应用内图像和菜单栏图标，主应用及卸载器使用修正后的 ICNS。
- 增加全部十个 iconset 文件的透明边距、主体比例与居中回归检查。
- 版本 `0.7.3`，构建号 `23`。DMG 在本地 Apple Silicon Mac 编译后上传。

### 验证与安装

- 旧版 ICNS 已复现缺少透明外边距；修正后的十个表示通过像素检查，最终 ICNS 反解后也通过尺寸、留白和居中检查。
- 现有逻辑及双语布局回归通过，两个应用的版本、图标、许可证、签名和 DMG 完整性已校验。
- 请正常退出旧版，再替换 `Applications` 中的应用。若系统仍显示缓存图标，可重新打开启动台或重新登录。
- 实际安装后的启动台显示尚未验收；不会自动修改本机已安装应用、清除图标缓存或重置启动台布局。

### 下载与许可证

下载 `MauLeaf-0.7.3.dmg`，将 `MauLeaf.app` 拖入 Applications。支持 Apple Silicon（arm64），macOS 13 或更高版本。安装包为本地 ad-hoc 签名，尚未进行 Apple notarization；首次打开可能需要在系统设置中按提示允许。可使用 `SHA256SUMS.txt` 校验下载文件。

项目采用 Apache-2.0，保留原始 ChargeCap MIT 声明；内置独立组件 batt 固定为 `v0.8.0`，遵循 GPL-2.0。本页附带其对应源码 `batt-v0.8.0-source.tar.gz`；MauLeaf 源码可通过 `v0.7.3` 标签或本页源码归档获取。

## English

### What's new

- Fixed the app icon appearing larger than other apps in Launchpad. The previous ICNS scaled artwork almost to the canvas edges. All sizes now include transparent margins, with artwork occupying about 80% of the canvas width.
- Preserved the original leaf design, in-app image, and menu bar icon. Both the main app and uninstaller use the corrected ICNS.
- Added regression checks for transparent margins, artwork scale, and centering across all ten iconset files.
- Version `0.7.3`, build `23`. The DMG was compiled locally on an Apple Silicon Mac before upload.

### Validation and installation

- Reproduced the missing transparent margin in the old ICNS. All ten corrected representations passed pixel checks; representations extracted from the final ICNS also passed size, margin, and centering checks.
- Existing logic and bilingual layout regressions passed. Versions, icons, licenses, signatures, and DMG integrity were verified for both apps.
- Quit the old app normally before replacing it in `Applications`. If a cached icon remains, reopen Launchpad or log in again.
- Actual Launchpad rendering after installation has not been validated. Installed apps, icon caches, and the Launchpad layout are not modified automatically.

### Download and licenses

Download `MauLeaf-0.7.3.dmg` and drag `MauLeaf.app` into Applications. Requires Apple Silicon (arm64), macOS 13 or later. The package is locally ad-hoc signed and has not been notarized by Apple; first launch may require approval through the prompts in System Settings. Use `SHA256SUMS.txt` to verify downloads.

The project uses Apache-2.0 and retains the original ChargeCap MIT notice. The bundled standalone batt component is pinned to `v0.8.0` and remains under GPL-2.0. Its corresponding source, `batt-v0.8.0-source.tar.gz`, is attached. MauLeaf source is available from the `v0.7.3` tag or the source archives on this page.
