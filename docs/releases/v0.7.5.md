# MauLeaf v0.7.5

[简体中文](#zh-cn) | [English](#english)

<a id="zh-cn"></a>
## 简体中文

本版引入 GitHub Actions 标签触发自动测试、双架构 DMG 构建与 Release 发布。Apple Silicon（arm64）正式版包含主应用、卸载器与经校验的 batt v0.8.0。

**Intel（x86_64）为实验预览版，只支持电池信息展示；禁用充电控制、batt 安装和卸载。Intel 充电控制未经验证，不代表完整兼容 Intel Mac。**

发布包含两个 DMG、SHA-256 校验文件和 GPL-2.0 batt 对应源码。安装包使用 ad-hoc 签名，尚未 Apple 公证。

<a id="english"></a>
## English

GitHub Actions now tests, builds and publishes a release when a version tag is pushed. The Apple Silicon (arm64) supported build includes the app, uninstaller and checksum-verified batt v0.8.0.

**Intel (x86_64) is an EXPERIMENTAL read-only preview. Charging controls and batt installation/removal are disabled. Intel charging hardware support has NOT been validated; full Intel compatibility is NOT claimed.**

Assets include both DMGs, SHA-256 checksums and corresponding GPL-2.0 batt source. DMGs use ad-hoc signing and have not been notarized by Apple.
