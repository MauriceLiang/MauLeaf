## 简体中文

### MauLeaf 0.8.0 — 正式发布

MauLeaf 0.8.0 完成了原生菜单栏交互、按需授权和 AppleSMC 限充控制架构的阶段整合。正式版仅提供 Apple Silicon arm64 安装包，不包含 batt 或 Intel 实验版。

#### 主要更新

- **菜单栏交互：** 保留简洁的绿色叶子；点击菜单栏即可查看电量、供电状态、限制充电和本次充满。顶部卡片的「限制充电」「本次充满」状态按钮可直接操作；充电上限展开区保留 50–95% 滑杆及快捷预设，移除重复控件。
- **减少管理员密码：** 启动应用、查看电池、调整未启用时的充电上限均无需管理员授权。用户首次主动开启限充时，才按需安装或升级特权 Helper。后续操作复用现有 XPC 服务。
- **退出流程：** 「保留组件并退出」先恢复并验证原始固件，再保留 launchd 服务注册，后台进程空闲后自行退出，下次启动无需重新授权；「移除组件并退出」恢复成功后清理已安装的系统组件，必要时请求管理员授权。
- **固件安全：** 首次启用前保存 bfF0、bfD0、bfE0 原始值与设备信息；修改上限和临时充满不覆盖快照；关闭/退出必须读回验证恢复结果，异常时保留可恢复的 Helper 与数据。旧版本、固件状态不明时不会静默写入新限充。
- **体验与质量：** 中文/英文状态及操作反馈优化；增加无 Helper 初次启动、旧服务修复、授权取消、退出恢复、固件失败及界面布局的自动化检查。

#### 兼容性与重要限制

- **当前原生写入严格限定：** MacBookPro18,1（Apple M1 Pro）、macOS 15、系统固件 mBoot-20457.41.3、arm64；macOS 26/27、Intel 及其他未验证机型不能新建充电限制。恢复已保存状态另行校验设备身份。
- **硬件验证仍有缺口：** 已有寄存器写入/读回及部分离线恢复验证，但预设充电停止点和恢复点尚未完成完整的真机长周期测试。正式版本号不应被理解为所有硬件或全部充电行为已经验证。
- **分发说明：** 此包使用 ad-hoc 代码签名，尚未使用 Apple Developer ID 签名及公证。安装时可能出现 macOS 安全确认。请仅从本仓库官方 Release 下载。
- 自动化测试使用模拟 SMC，不会在 GitHub Actions 机器上写入真实电池固件；请在已验证的目标设备上谨慎使用。

## English

### MauLeaf 0.8.0 — Stable release

MauLeaf 0.8.0 consolidates the native macOS menu-bar UI, explicit first-use authorization, and guarded AppleSMC charge-limit controls. This release ships **Apple Silicon arm64 only**, with no batt binary and no experimental Intel package.

#### Highlights

- **Direct controls:** Compact green-leaf menu-bar panel with battery percentage, power supply, limit state and one-time full charge. Click the top-card charging-limit or one-time-full status pill directly; the expandable limit section retains the 50–95% slider and presets without duplicate action buttons.
- **Fewer password prompts:** Launch, battery inspection and editing an inactive limit require no administrator password. The privileged Helper is installed or upgraded only after explicit opt-in to enabling charging limits, and subsequent actions reuse the installed XPC service.
- **Safe exit:** Keep-and-Quit first restores and verifies original firmware, then keeps the on-demand launchd registration so future launches do not reinstall it. Remove-and-Quit cleans up installed privileged components after verified restoration and requests administrator authorization when required.
- **Guarded firmware operations:** Original bfF0/bfD0/bfE0 values and device identity are snapshotted before the first write; later changes never overwrite the original. Restoration is independently verified; unknown or older helper states cannot silently trigger a new limit.
- **Polish and regression tests:** Improved Chinese/English status feedback plus simulated SMC coverage of first-use setup, legacy helper repair, authorization failure, safe exit and UI behavior.

#### Compatibility and limitations

- **New firmware writes are restricted** to MacBookPro18,1 (M1 Pro), macOS 15, firmware mBoot-20457.41.3 and arm64. macOS 26/27, Intel and unverified devices cannot activate new limits. Stored-state restoration has separate identity checks.
- **Hardware-validation gap:** Register read-back and selected unplugged restoration tests are available, but the actual charge-stop and resume percentages still require extended physical testing. A stable version label does not imply complete hardware qualification.
- **Distribution:** The package is ad-hoc code-signed, not yet Developer ID signed or notarized. macOS may display security prompts; download only from this repository's official Release.
- Automated CI runs against a fake SMC backend and does not write real battery firmware.
