## 简体中文

### MauLeaf 0.9.1-preview.2 — Helper 兼容升级与安全卸载

此预览版本面向 **Apple Silicon arm64**，仍仅允许限定的 M1 Pro/macOS 15/指定固件组合写入充电上限。

#### 主要修复
- **Helper 独立版本管理**：将 `helperBuildVersion`（当前 `1.0.0`）与 XPC 协议版本（`5`）分离，不再跟随 MauLeaf 界面版本更新。
- **启动时兼容检查**：读取 Helper 协议版本；兼容时直接使用，不安装、不索取管理员密码；已安装且旧版协议不兼容时，启动后请求管理员授权安全升级。未安装 Helper 的首次启动仍只读，不会自动安装。
- **防止危险降级**：发现比当前 App 更新、尚未支持的 Helper 协议时，不自动覆盖或删除。
- **安全更新与回滚**：安装时先校验二进制签名、服务标识和 root 所有权，再备份旧文件、替换并验证 LaunchDaemon；失败时尝试回滚，绝不主动删除固件原始快照、一次充满或恢复任务。
- **跨版本卸载修复**：取消卸载时“已安装 Helper 必须与当前应用内置二进制逐字节相同”的错误前提。要求签名与身份有效、确认原始固件已恢复，才允许移除系统组件。UI 单独升级不再导致退出码 9。
- **设置一致性**：将“超限优先适配器”的 macOS 开关改为与“显示当前电量”“界面语言”相同宽度的原生分段选择。
- 新增 Helper 兼容重用、旧版自动升级一次、未知新版本拒绝降级、卸载安全边界等自动化测试。

#### 安全限制
- **超限优先适配器依然是只读监测，不能把已经高于上限的电池切换为适配器供电。** 此次修复不涉及新的 SMC 控制键。
- 系统级 Helper 首次安装、升级和移除可能需要 macOS 管理员授权；不兼容时只尝试一次自动升级，失败后保留恢复数据并提供人工修复入口。
- 老旧、无法识别或无法完成恢复验证的 Helper 必须保留后台恢复组件。**不承诺通过跳过校验强行卸载任意未知版本。**
- 当前仍使用 ad-hoc 签名；安装和卸载会要求预期签名标识、root-owned 安装文件和受验证的恢复结果。

## English

### MauLeaf 0.9.1-preview.2 — Helper compatibility and safe uninstall

This **Apple Silicon arm64** preview retains the current M1 Pro / macOS 15 / specified firmware write allowlist.

#### Changes
- Exposes a separate Helper build version (`1.0.0`) and compatible XPC protocol (`5`), independent of the app version.
- Checks compatibility on startup. A compatible installed Helper is reused with no password or reinstallation. Outdated installed Helpers are upgraded after a macOS administrator authorization prompt. First-time launch without a Helper remains read-only.
- Refuses to automatically downgrade a newer, unknown Helper protocol.
- Installer stages and validates replacement files, saves the previous install for rollback, and never deletes battery snapshots or pending restoration records.
- Removes byte-for-byte binary comparison from cross-version uninstall; trust is based on signed expected identity, root ownership and independent verified firmware restoration.
- Aligns the experimental above-limit preference with the other native segmented Settings controls.
- Adds regression coverage for compatibility, upgrading, newer-protocol downgrade protection and uninstall safeguards.

#### Limitations
- Above-limit adapter preference **still only observes battery telemetry**. It does not force adapter power or prevent discharge. No new SMC writes are introduced.
- Installing/upgrading/removing a privileged Helper may require admin authorization. Unknown old Helpers that cannot prove successful firmware restoration must preserve their recovery components rather than force deletion.
- The release still uses ad-hoc code signing, and actual hardware control requires validation on the allowlisted Mac.
