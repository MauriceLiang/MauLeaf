## 简体中文

### MauLeaf 0.9.1-preview.3 — 即时更新充电器连接状态

MauLeaf **Apple Silicon arm64** 预览版。

#### 本次修复
- 修复拔掉充电器后菜单栏仍短暂显示“已连接电源 / 正在充电”的延迟：订阅 macOS 原生 IOKit 电源变化通知，有变化时立即更新。
- App 使用 I/O Registry 直接读取 AppleSmartBattery 数据，避免为每次界面刷新启动 `ioreg` 子进程。
- 电源事件触发即时读取，并在 350 毫秒和约 1.2 秒后做两次短暂复查，以适应系统在拔插电源时可能出现的字段更新滞后；原来的 20 秒轮询作为漏事件时的兜底，不新增高频常驻轮询线程。
- 特权 Helper 的电源判断继续使用原先经过测试的读取方式。本次没有调整 Helper 协议、构建版本、SMC 固件限充键、授权、恢复或卸载策略。
- 新增拔电/插电立即刷新、原生属性解析与不触发 Helper 操作的模拟测试。

#### 限制与真机验证
- CI 模拟测试不能保证每台 Mac 的系统电源通知均在固定毫秒数内送达。实际界面响应还受 macOS 的电池驱动、IORegistry 更新时机影响。
- “超限优先适配器”仍是 **只读放电监测**，不会让高于充电上限的 Mac 强制使用适配器供电。此版本只修复电源状态更新延迟。
- 目标限充设备仍为既定 M1 Pro / macOS 15 / mBoot-20457.41.3 组合。

## English

### MauLeaf 0.9.1-preview.3 — Immediate AC plug/unplug UI updates

A new **Apple Silicon arm64** preview focused on power status responsiveness.

#### Changes
- Listen to macOS IOKit power-source notifications instead of waiting for the 20-second polling fallback before updating the card after a charger is connected/disconnected.
- Read AppleSmartBattery directly from the I/O Registry in the app, avoiding repeated `ioreg` process creation during UI refreshes.
- Refresh instantly and perform bounded follow-up samples at ~350 ms and ~1.2 s to accommodate OS property propagation; keep the existing 20-second low-frequency fallback.
- Keep the privileged Helper's previously verified power-safety reader unchanged. No changes to Helper protocol/build, SMC firmware writes, authorization, restoration or uninstallation.
- Add simulated unplug/replug event tests, native-property parsing tests and guard against unintended Helper requests.

#### Limitations
- macOS and its battery driver control event-delivery timing, so no guaranteed fixed latency can be claimed without target-device validation.
- The experimental above-limit adapter preference is **read-only monitoring** and cannot prevent battery discharge or redirect power. This preview only fixes stale UI telemetry.
