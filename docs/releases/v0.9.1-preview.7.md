## 简体中文

### MauLeaf v0.9.1-preview.7 — 顶部供电流向图

以最终确认的深色菜单栏设计为基础，**供电详情图直接取代顶部的大号电量百分比**，不再在图下方重复显示“总输入 / 系统功耗 / 充电功率”等统计条，也不再单独保留重复的「供电状态」行。

- 顶部卡片：**供电详情**标题 + 当前状态胶囊（适配器供电 / 充电中 / 电池供电 / 电池辅助供电 / 状态未知）。
- 节点内部直接显示功率：适配器、系统、电池充电或放电；连接流向按实际状态改变。简洁深色外观，小圆角和柔和蓝/绿/橙色区分含义。
- 四种场景：电池 → 系统；适配器 → 系统；适配器 → 系统及电池；适配器 + 电池 → 系统（插电仍放电时）。
- **数据只来自本机只读 AppleSmartBattery / IORegistry**：`Voltage × Amperage` 为电池端功率；`PowerTelemetryData.SystemPowerIn` 为外部输入的系统采样值；已知同一采样期的适配器输入与电池功率可用于估算系统功率。**不允许使用 `AdapterDetails.Watts` 充电器额定瓦数伪装实际输入**。
- 数据缺失、供电状态未知、数据相互矛盾时显示 `—`，不会填入默认功率或示例数字。流线用于表达方向，不作为经过校准的精确瓦数比例；系统传感器可能滞后，不能宣称毫秒级数据同步。
- 原来的「显示当前电量」设置替换为「显示供电详情」，**默认开启**，用户可隐藏；仅影响菜单栏展示，不触发硬件控制或授权。
- 保留「限制充电」「本次充满」「充电上限」「设置」「退出 MauLeaf」及原有固件恢复与动态保电逻辑，且禁用可滚动的弹窗。
- 新增传感器单位和无数据测试、四状态流向模型测试、简体中文 / 英文 328pt 窄屏几何布局测试。
- **独立 Helper 的协议仍为 v6，构建版本仍为 1.3.0**。本次仅改 UI 与只读采样，不会导致重装 Helper 或重复请求管理员权限。

**重要：** 供电图用于理解当前系统采样状态，不能替代硬件功率计。此前目标 Mac 在限充开启时可能出现拔电状态延迟，本次纯展示改造不修复这个固件/系统上游问题；拔电时恢复原始 SMC 参数的 Preview 6 安全机制不变。

## English

### MauLeaf v0.9.1-preview.7 — Top Power Flow Diagram

The top header now shows a native, compact power-flow diagram instead of large battery percentage digits, with measured watts placed directly inside the source and destination nodes. There is **no redundant bottom wattage summary** and no duplicate stand-alone power-state row.

- Readable modes: battery → system, adapter → system, adapter → system and battery charge, and battery-assist when the adapter is connected but the battery still discharges.
- Reads `Voltage`, signed current, and `PowerTelemetryData.SystemPowerIn` via the existing app-only read-only IORegistry path. The charger's *rated capacity* (`AdapterDetails.Watts`) is never presented as live input draw. Contradictory or missing data is shown as a dash rather than fabricated.
- Flow ribbons indicate direction, not calibrated Sankey energy proportions. Reported power may update slower than the UI.
- The settings option is now **Show Power Flow**, enabled by default. The panel remains native, non-scrolling, and available in both Chinese and English.
- No new firmware writes, no special daemon, no new privileged API or background polling. Helper stays at **v6 / build 1.3.0**, so an app-only presentation update does not require Helper replacement.
- The safe exact-SMC-on-unplug restoration and one-time-full-charge policies from Preview 6 are unchanged.

**Limitations:** Hardware telemetry can be missing or stale, and this preview does not assert that firmware-managed battery drain or macOS' delayed unplug reporting is fixed.
