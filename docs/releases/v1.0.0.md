## 简体中文

### MauLeaf 1.0.0 — 正式版

MauLeaf 1.0.0 以 `v0.9.1-preview.11` 已合并至 `main` 的功能为基线，发布 **macOS 15 Apple Silicon arm64 DMG**，不在正式化过程中改动固件控制实现。

#### 主要功能

- **原生菜单栏界面**：绿色叶子图标，点击直接显示单张简洁原生卡片；无主窗口及整张卡片滚动，支持中文/English 和浅色/深色模式。
- **限制充电 / 本次充满**：50–95% 可选上限、70/75/80/85/90/95% 快捷预设；仅用户主动启用限充时才可能申请 Helper 管理员授权。本次充满期间暂停动态保电。
- **动态保电（可选）**：超过用户目标电量时尝试保持当前电量，使用临时固件上限；已测试设备中该策略启用后的供电及拔电反馈正常，但普通固定上限模式仍可能存在拔电状态识别延迟，尚需继续排查。
- **实时供电图**：参考 Apache-2.0 开源项目 [Status Trio](https://github.com/lingyired/status-trio) 的布局与采样方式，面板打开时约每 2 秒采集一次只读功率数据，按适配器 / 系统 / 电池充放电绘制流向；缺少或冲突的传感器数据不虚构数值。关闭详情图后保留与右上角一致的供电状态胶囊；隐藏时停止额外的 2 秒功率采样。
- **退出行为预设**：在设置中选择「退出时移除组件」，默认关闭（保留组件）。每次正常退出先恢复原始 SMC 固件值并读回验证；启用移除后才清理 Helper、LaunchDaemon 与脚本，不再每次退出弹窗询问。**建议卸载前开启移除，正常退出并确认清理成功，再删除 App。**
- **可靠恢复**：首次修改前保留原始 SMC 寄存器及设备身份快照，拔电、重启、主动关闭、退出、异常状态按现有安全条件恢复或保留延迟恢复任务；未经验证的恢复绝不报告成功。固件/Helper 状态保持独立 20 秒兜底检查，插拔电事件由 IOKit 监听。
- **诊断和反馈**：附带只读 `Scripts/diagnose-mauleaf.sh`，无法使用时可将脱敏诊断结果附到 GitHub Issue，脚本不读取私密序列号、不上传数据、不进行固件写入。

#### 兼容性、安全与限制

- **仅允许新建限充的目标配置**：MacBookPro18,1（Apple M1 Pro）+ macOS 15 + mBoot-20457.41.3 + arm64。macOS 26/27、Intel 与其他未经验证的组合不能启用新的固件写入。其他配置可视情况仅查看只读电池信息。
- 动态保电开启时的电源行为已在目标机器观察到改善；**普通限充模式下的拔电识别延迟尚未解决**。物理拔电后固件恢复依赖可靠的系统电源状态与安全条件，不能保证瞬时发生。
- 真实充电停止 / 再启动的精确百分比尚未完成完整全周期实机验证。读回固件寄存器成功不等同于所有硬件上的实际电池行为已验证。
- 仍采用 **ad-hoc 签名，未进行 Apple Developer ID 签名或公证**。请仅从本仓库正式 GitHub Release 获取安装包。
- 正式版 CI 包括模拟固件状态回归、中英文布局、深浅色 / 多供电模式测试、Helper 安全检查及 Apple Silicon DMG 打包验证；CI 不会在测试机上执行真实的 SMC 写入。
- 保持特权 Helper 协议 XPC v6 / build 1.3.0，升级应用界面不会无故重复安装兼容的 Helper。

#### 获取与升级

从 [最新正式版](https://github.com/MauriceLiang/MauLeaf/releases/latest) 下载 `MauLeaf-1.0.0-macos-arm64.dmg`。如果从预览版升级，保留应用已有偏好与可信恢复信息；安装后请确认供电状态、动态保电和退出设置符合预期。进行真正的卸载前，必须先恢复原始固件并清理系统组件。

## English

### MauLeaf 1.0.0 — Stable release

MauLeaf 1.0.0 promotes the already-merged `v0.9.1-preview.11` functionality to a stable **macOS 15 Apple Silicon arm64** release, without changing the privileged firmware controller in this release promotion.

#### Highlights

- **Native menu-bar experience:** A green leaf icon opens one compact SwiftUI/AppKit popover with Chinese/English localization, light/dark appearances, no main window and no whole-panel scrolling.
- **Charging limit and one-time full charge:** 50–95% limits with 70/75/80/85/90/95% shortcuts. Helper authorization is only requested for explicit firmware-control actions, not ordinary startup or telemetry. Dynamic Hold pauses during one-time full charge.
- **Optional Dynamic Hold:** When above the target percentage, can apply a temporary firmware ceiling to reduce discharge. On the tested Mac, power behavior and unplug feedback improve while Dynamic Hold is enabled; fixed-limit unplug-state latency is still a separate unresolved issue.
- **Live native power flow:** Drawing and read-only telemetry adapted from the Apache-2.0-licensed [Status Trio](https://github.com/lingyired/status-trio), sampling at approximately 2-second intervals only while the full diagram is visible. Compact mode retains the identical supply-status badge without the wattage diagram or additional 2-second polling; invalid measurements never become fabricated proportional flows.
- **Persistent quit policy:** The "Remove components on quit" preference defaults to Off. Every normal quit first restores and verifies the original firmware state; On additionally cleans the installed privileged Helper, LaunchDaemon and scripts. No repeated normal-quit chooser. **Enable removal, quit successfully and verify cleanup before deleting the app.**
- **Fail-closed recovery:** Original SMC and device identity snapshots, unplug/reboot restoration and deferred recovery retain existing safety gates. IOKit power-source events and the independent 20-second Helper safety fallback remain in place.
- **Read-only diagnostics:** The bundled diagnosis script supports redacted bug reports without networking, privileged writes, or collecting device serials.

#### Compatibility and important limits

- New firmware charge-limit operations are restricted to **MacBookPro18,1 (M1 Pro), macOS 15, firmware mBoot-20457.41.3, arm64**. macOS 26/27, Intel and other unvalidated systems are not authorized to perform new firmware writes.
- Fixed-limit unplug detection may still lag on the tested Mac. Real charge stop/resume percentages have not undergone complete full-cycle hardware validation. Successful SMC register read-back is not proof of universal physical charging behavior.
- The installer is **ad-hoc signed without Apple Developer ID signing or notarization**. Download from this repository's official Release.
- Automated CI uses a simulated SMC backend and tests localized popovers, firmware safety and arm64 DMG packaging; it does not write firmware on CI hosts. Helper protocol remains XPC v6 / build 1.3.0.

#### Install / upgrade

Download `MauLeaf-1.0.0-macos-arm64.dmg` from the [latest stable GitHub Release](https://github.com/MauriceLiang/MauLeaf/releases/latest). Upgrades retain existing preferences and trusted recovery state. For complete uninstallation, safely restore and verify firmware, remove system components through the app's quit setting, then move the app to Trash.
