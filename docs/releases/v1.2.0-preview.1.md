## 简体中文

Apple Silicon（arm64），已验证的固件控制范围仍为 macOS 15 指定机型。

- 重组主应用源码目录、拆分应用入口、菜单栏、界面与充电管理；统一构建源码清单。
- 新增全局外观：跟随系统、浅色、深色。设置持久化。
- 设置使用原生拨动开关、外观分段选择及语言菜单，保留动态保电及卸载安全说明。
- 压缩操作条栏与退出区域的底部留白，保留原有状态胶囊。
- 供电详情仅调整颜色、透明度及对比度，原有图标、字体、节点几何与数据采样不变。
- Helper 1.7.0、XPC v9、固件控制及恢复机制不变。MagSafe 灯光功能留待 1.3.0。

预览版需实机验证外观、菜单布局及性能；不替代正式版。

## English

Apple Silicon (arm64); firmware write support remains limited to validated macOS 15 hardware.

- Organize app sources and centralize build source lists.
- Add persistent System, Light and Dark appearance settings.
- Use native switches, a segmented appearance picker and a language menu while retaining safety descriptions.
- Tighten action rows and bottom spacing; preserve status capsules.
- Improve Power Flow color contrast only; retain geometry, symbols, fonts and sampling.
- Helper 1.7.0 and XPC v9 unchanged; MagSafe LED control is deferred to 1.3.0.

Preview for real-device UI and performance verification.
