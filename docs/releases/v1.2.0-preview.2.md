## 简体中文

适用于 Apple Silicon（arm64）。固件写入兼容范围不变。

- 外观改为原生「浅色模式」开关：默认关闭（深色），开启即为浅色，选择即时生效并持久化；原跟随系统设置回退为深色，原明确选择的浅色或深色继续保留。
- 仅加深浅色模式下的绿色启用状态文字、盾牌图标、胶囊底色和设置开关，提高白底可读性。供电状态绿点同步加深；深色配色不变。
- 保留供电详情的图标、字体、排版、节点几何、连接形状及采样。
- Helper 1.7.0、XPC v9、充电控制与恢复流程不变。MagSafe 指示灯控制留至 1.3.0。

## English

Apple Silicon (arm64); firmware write compatibility is unchanged.

- Replace the appearance picker with a native Light Mode switch, off by default (dark). Preserve explicitly saved light/dark preferences; the old System setting falls back to dark.
- Improve only light-mode green contrast for active charging controls, icons, switches and the power status dot. Dark colors are unchanged.
- Preserve Power Flow geometry, icons, typography, layout and sampling.
- Helper 1.7.0, XPC v9 and firmware safety behavior are unchanged. MagSafe LED control remains deferred to 1.3.0.
