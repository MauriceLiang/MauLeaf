## 简体中文

### MauLeaf 1.2.0 — 正式版

基于已通过 CI 回归测试、ARM64 打包及发布后下载校验的 1.2.0-preview.2。应用 **1.2.0**，Helper **1.7.0**，XPC **v9**。

- **结构维护**：按应用入口、菜单栏、视图、充电业务、供电采样、固件、Helper 和公共模块组织源码，统一应用与 Helper 的构建输入，保留原有充电状态管理。
- **全局外观**：默认深色。设置中开启「浅色模式」即切换浅色，关闭恢复深色，选择即时生效并持久化。此前明确选择的浅色或深色保留，旧跟随系统配置回退为深色。
- **界面精修**：压缩操作条栏与退出行底部留白，保留状态胶囊按钮。设置使用原生拨动开关及语言下拉菜单，保留动态保电、卸载安全说明与强制重置确认。
- **供电详情**：增强文字、图标、节点和连接带的颜色对比度；不改变原有图标、字体、排版、节点几何、功率计算与采样。浅色绿色加深，preview.2 保持深色绿色不变。
- **稳定性**：Helper 及固件核心源码内容与 1.1.0 一致，仅整理目录。充电安全机制、原始快照、恢复与快速退出流程不变；未引入第三方依赖、额外后台进程或 MagSafe 指示灯控制（留至 1.3.0）。

#### 兼容性与安全

- Apple Silicon arm64；新固件限充仍仅允许 MacBookPro18,1（M1 Pro）/ macOS 15 / mBoot-20457.41.3 的已验证组合，不扩大硬件或系统支持。
- CI 使用模拟固件与界面渲染验证，不能替代实际充电周期、退出耗时或完整真机验证。
- 快速退出表示后台已接收恢复任务，不表示硬件恢复已经完成；卸载前开启退出时移除组件，并确认恢复和清理完成。
- 安装包采用 ad-hoc 签名，未公证。已有匹配 Helper 可复用；不兼容组件仍按现有安全流程处理。

## English

### MauLeaf 1.2.0 — Stable release

Based on 1.2.0-preview.2, which passed CI regression tests, ARM64 packaging and downloaded release asset verification. App **1.2.0**, Helper **1.7.0**, XPC **v9**.

- **Maintainability:** Organize sources by app lifecycle, menu bar, views, charging, power sampling, firmware, Helper and shared code; centralize compile inputs without replacing the existing charging state manager.
- **Appearance:** Dark by default. Turn on Light Mode in Settings to switch to light appearance, or off to return to dark; persist the choice. Existing explicit light/dark choices remain; the old System preference falls back to dark.
- **UI refinement:** Tighten action rows and bottom spacing while preserving status capsules. Use native switches and a language menu, retaining Dynamic Hold and uninstall safety descriptions and reset confirmation.
- **Power Flow:** Improve contrast without changing symbols, fonts, layout, geometry, power calculations or sampling. Dark green remains unchanged from preview.1; light-mode green is darker.
- **Stability:** Firmware and Helper source contents match 1.1.0; only their paths changed. Preserve firmware safety, snapshots, recovery and fast quit. No new dependencies, background processes or MagSafe LED control (deferred to 1.3.0).

#### Compatibility and safety

- Apple Silicon arm64; new firmware limits remain restricted to the validated MacBookPro18,1 (M1 Pro), macOS 15 and mBoot-20457.41.3 configuration.
- Simulated firmware and UI-rendering CI are not a substitute for full physical charge cycles, quit latency or complete hardware validation.
- Fast quit confirms durable recovery handoff, not completed hardware recovery. Enable component removal before uninstalling and verify recovery and cleanup first.
- Ad-hoc signed, not notarized. Compatible Helpers are reused; incompatible components follow the existing guarded upgrade procedure.
