## 简体中文

- App 1.3.0 / Helper 1.8.0 / XPC v9。
- 新增独立 MagSafe 3 指示灯控制：确认 MauLeaf 已授权的有效限充、MagSafe 连接、实际停充及原始电量接近上限时，尝试切换绿灯；保持区间内避免重复写入。
- 正常充电、本次充满、关闭限充、断开电源和退出时交还系统控制，不强制橙灯。
- 使用实机验证过的 ACLC size-only 请求和延迟回读。原有 bfF0、bfD0、bfE0 写入、快照及恢复逻辑不变；新增持久灯光恢复标记，失败保留恢复能力。
- 复用现有 Helper 状态刷新及恢复机制，不新增常驻进程、独立轮询或设置项。
- 仍仅在已验证 MacBookPro18,1 / macOS 15 / mBoot-20457.41.3 / arm64 组合开放控制。未知端口或充电观测时不接管。
- **预览验证重点**：实际 MagSafe 端口识别、达到上限、动态保电、恢复充电、拔插、睡眠唤醒、退出及卸载。正常后台刷新最长约 20 秒，睡眠中不保证即时更新。自动交还依据指令接受，真实灯光需实机确认。升级 Helper 可能需要一次管理员授权。勿在恢复未完成时降级或手动删除 Helper。

## English

- App 1.3.0 / Helper 1.8.0 / XPC v9.
- Independent MagSafe 3 LED preview: request green only for a verified MauLeaf-owned active limit, detected MagSafe connection, non-charging state and raw capacity near the upper threshold; retain green in the same hold band.
- Hand control back to macOS on charging, full-charge override, disable, unplug and quit. Never force orange.
- Use the hardware-proven size-only ACLC request and delayed readback. Charging registers, original snapshots and charge restoration logic are unchanged; a durable LED recovery marker protects interrupted handoffs.
- Reuse existing status refresh and recovery; no extra process, polling timer or settings.
- Restricted to the existing validated device/OS/firmware combination. Unknown observations fail closed.
- Preview requires real-device port detection, charging transitions, sleep/wake, reconnect and quit/uninstall tests. Background refresh can take up to about 20 seconds; no real-time sleep guarantee. Automatic handoff is command acceptance, not a guaranteed physical color. Helper upgrade may require one administrator authorization. Do not downgrade or manually remove the Helper while recovery is pending.
