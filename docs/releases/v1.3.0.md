## 简体中文

### MauLeaf 1.3.0 — 正式版

应用 **1.3.0**，Helper **1.8.0**，XPC **v9**。

- **MagSafe 3 指示灯**：在已授权的有效限充、确认 MagSafe 接入及停充且电量接近上限时尝试设为绿灯。正常充电、本次充满、关闭限充、断电及退出时交还系统控制，不强制橙灯。
- **独立灯光控制**：采用实机探针验证过的 ACLC size-only 写入方式及延迟回读；持久恢复标记用于异常退出后的控制权交还。未完成交还时保留恢复服务。
- **统一深色外观**：移除浅色模式及其设置、持久化偏好、配色与本地化分支。升级后固定深色，不跟随 macOS 外观；原深色供电图布局、图标、字体及颜色保持不变。
- **保持轻量**：复用现有状态刷新及恢复机制，不新增独立轮询、常驻进程或第三方依赖。拔插电源后的自动限充恢复调度保持不变，允许系统状态更新和稳定等待。

#### 兼容性与安全

仅 Apple Silicon arm64；新固件控制仍限于 MacBookPro18,1 / macOS 15 / mBoot-20457.41.3 的已验证组合。未知端口、电源或充电状态不接管灯光。Helper 升级可能需要一次管理员授权。灯光更新受现有后台刷新及 macOS 调度影响，不保证即时。正常退出的恢复任务接收不等于恢复完成；卸载前启用移除组件并确认完成。不要在恢复未完成时降级或手动删除 Helper。CI 与探针不能替代完整实机生命周期测试。安装包 ad-hoc 签名，未公证。

## English

### MauLeaf 1.3.0 — Stable release

App **1.3.0**, Helper **1.8.0**, XPC **v9**.

- **MagSafe 3 LED:** Request green for a verified MauLeaf-owned active limit, detected MagSafe connection and non-charging state near the upper threshold. Return control to macOS during normal charging, one-time full charge, disable, unplug and quit; never force orange.
- **Independent LED control:** Use the hardware-probed size-only ACLC request and delayed readback; a durable marker protects interrupted handoffs. Preserve recovery capability until handoff completes.
- **Dark-only interface:** Retire the alternate appearance, switch, stored preference, palette and localization branches. Preserve the existing dark power-flow geometry, icons, typography and colors. The app stays dark independently of macOS appearance.
- **Lightweight operation:** Reuse existing refresh and recovery paths without extra persistent processes, polling timers or dependencies. Existing disconnect/reconnect charge-limit scheduling is unchanged; allow system observations to settle.

#### Compatibility and safety

Apple Silicon arm64 only. New firmware control remains limited to the validated MacBookPro18,1 / macOS 15 / mBoot-20457.41.3 combination. Unknown port or battery observations do not authorize LED takeover. Helper upgrade may require one administrator authorization. LED and reconnect updates depend on existing refresh and system scheduling, not real-time guarantees. Quit acknowledgment is not completed recovery; verify removal before uninstalling. Do not downgrade or delete the Helper while recovery is pending. CI and hardware probes do not replace full real-device lifecycle validation. Ad-hoc signed, not notarized.
